# CSCB58 Assembly Project
This is my final project submission for CSCB58 (Computer Organization) at UTSC for Winter 2025. 

This is a simple platformer game written in MIPS assembly. The following features are also present in the game:
- Double Jump
- Start menu
- Moving objects/platforms
- Win/fail conditions

## Demo
A demo of the game can be seen [here](https://youtu.be/vSMBMO7GK7o)

## Usage
The game can be run on the MARS MIPS simulator.
